# 恒存 EVERKEEP

一个看起来像正经 SaaS 官网的页面。
往下滚，它会开始不对劲。
滚到底，你就明白了。

纯前端，零依赖，三个文件。

## 运行

直接双击 `index.html` 就能看。或者起个本地服务器：

```bash
python -m http.server 8777
# 打开 http://127.0.0.1:8777/
```

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 全部文案与结构。每个会"坏掉"的文字都带 `data-mut` |
| `style.css` | 两套视觉语言：干净的营销排版 → 失血的黑暗 |
| `script.js` | 滚动叙事引擎、文字溃烂、程序化照片、巨脸渲染、WebAudio |

`preview/` 是沿途截图，`_dev/` 是开发用的 CDP 截图脚本，删掉不影响运行。

## 叙事结构

整页是一条单向的线，**溃烂进度只增不减**——你往回滚，文字不会恢复。这不是 bug，是设计。

| 滚动进度 | 发生什么 |
| --- | --- |
| 0 – 15% | 一切正常。Hero、媒体背书、功能卡片、数据、用户评价、定价 |
| 15 – 40% | 文字开始偶尔抽动。导航栏先坏（`功能` → `埋 藏`），然后卡片文案逐块溃烂 |
| 40 – 45% | 黑潮从底部涌上来，像墨水倒扣。整个页面（含导航）被吞进黑暗 |
| 45 – 60% | 黑暗中一只巨大的眼睛。瞳孔跟着鼠标转，偶尔眨一下。血丝慢慢浮上来 |
| 60 – 78% | 照片墙。2,438,901 张照片，一张张醒来，然后全部变成同一张脸 |
| 78 – 95% | 一张凑得太近的脸从黑暗里浮出来。它一直在靠近 |
| 95% – 100% | 一道闪帧，然后只剩下「备份完成。」 |

## 几个机制

**文字溃烂**：每个 `data-mut="正常|有点怪|很怪|恐怖"` 的元素，会在滚动到它附近时逐字"被替换"。中间态是随机汉字，像信号在衰减。

**照片**：全部是 canvas 画出来的，没有任何图片文件。同一张缩略图有两层——正常照片和那张脸。滚动时交叉淡入。

**巨脸**：同样用 canvas 逐帧绘制。头顶沉在黑暗里，只有眼窝、鼻梁、下颌一带有微弱的光。这是故意的——看不清比看清楚更吓人。

**声音**：默认关闭。页面底部弹一个 Cookie 提示（对，就是那个），点「接受」之后才会起 WebAudio：低频 drone、心跳、耳鸣，全随滚动深度变化。点「拒绝」会失败，试几次之后按钮会消失。

## 小细节，自己找

- 滚回去会提示「上行通道已关闭」
- 标签页标题会一路变成「别回头」
- 用户数在你滚动时会悄悄 +1
- 评价区有一条灰色的「删不掉。我试过了。」
- 结尾那个「关闭」按钮点了不会关
- 整页光标是反色混合的，在深色场景里会自己变白

## 调试

URL 后面可以加参数直接跳到某处：

```
?y=40%                        # 滚到文档 40% 处
?at=%23sceneFace&p=0.5        # 把巨脸场景滚到 50% 进度
```

## 注意

页面含闪烁画面（约在 95% 处）和持续低频音效。
有光敏性癫痫史的话，别滚到底。
